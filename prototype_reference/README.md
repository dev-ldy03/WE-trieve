# 소지품 분실 서비스 프로토타입

`index.html`을 브라우저에서 열면 바로 실행됩니다. 외부 라이브러리나 설치가 필요하지 않습니다.

홈 → 물건 상세 → 찾기 → 재구매 지원 → 지원 신청 흐름을 확인할 수 있습니다. 물건 추가, 알림 설정, 찾아본 장소 표시, 여러 물건 선택도 동작합니다.

위치·연결·추천·요금·지원 조건은 예시입니다. 실제 기기 연결, AI 추론, 결제, 자료 업로드, 지원 접수는 수행하지 않습니다. 입력한 정보는 메모리에만 남으며 새로고침 시 초기화됩니다.

## 찾기 흐름

- 동선 복기: 방문 장소와 교통 이용 기록을 지도·시간순 목록으로 확인하고 찾아본 곳을 표시합니다.
- 온라인 탐색: 분실물 게시물 예시를 출처별로 보고 내 물건과 비교하거나 후보로 저장합니다.
- 신고·문의: 장소별 연락처와 문의 문구, 분실 신고 절차를 확인하고 진행 상태를 기록합니다.

지도, 교통 기록, 게시물, 연락처는 시연용 데이터입니다. 실제 위치 조회나 전화 연결, 외부 사이트 신고는 수행하지 않습니다.

## 실행

저장소를 다운로드한 뒤 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버가 필요하지 않습니다.
